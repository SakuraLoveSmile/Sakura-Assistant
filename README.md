# Assistant（个人助手 MVP）

一台 Android 手机掌握两台设备与反馈服务的健康状况：

- 公网服务器与飞牛 NAS 的 CPU / 内存 / 磁盘 / 网络 / 容器 / 硬盘 SMART / 存储池状态与趋势；
- Feedback 新反馈、处理错误与恢复通知（含截图、日志附件按需读取）；
- 故障待处理队列：同一故障合并、已读 / 静音 / 自动恢复、历史查询；
- 可靠通知：原生前台服务推送，23:00–08:00（Asia/Shanghai）免打扰与结束汇总。

## 模块

| 目录 | 技术 | 说明 |
|---|---|---|
| `hub/` | Go + SQLite | 认证、指标接入与汇总、事件去重/乱序、故障状态机、规则引擎、SSE、附件代理 |
| `agent/` | Go | 设备采集：基础指标、容器、SMART（不唤醒休眠盘）、存储池；断连持久队列补传 |
| `app/` | Flutter + Kotlin | Dart 界面（首页/详情/历史/接入/设置）+ 原生前台服务与通知 |
| `contracts/` | 文档 | 已冻结接口契约（api / events / bridge / feedback）与示例载荷 |
| `deploy/` | compose | 中枢部署骨架与环境样例 |

接口以 `contracts/` 为准；开发约定与验证命令见 `AGENTS.md`。

## 服务器接入

中枢 1.2.0 新增通过中枢 HTTPS 域名下载、安装 Agent 的能力：在 App「接入管理」
创建「设备采集」来源，复制安装命令到 Linux 服务器，按提示隐藏输入一次来源密钥。
安装器识别 amd64/arm64，校验下载、配置 systemd 开机自启，并确认指标已被中枢接收。
被监控设备无需开放入站端口；现有 APK 无需升级。

必须先发布对应 Agent 资产、部署新版中枢才能使用真实链接；源码完成不代表线上已更新。
安装、升级、轮换密钥和排障见 [服务器接入说明](docs/agent-install.md)。
